## 二、代码文件说明

### 2.1 scripts/factor.py（核心生产代码）

**功能**: 计算 Graham NCAV 折价因子，生成 buy/sell/hold 信号

**关键修复**:
- ✅ 替换全部三个 NotImplementedError，使用真实 PandaAI SDK 重写
- ✅ 删除 pa.BufferReader 解析层（SDK 直接返回 DataFrame）
- ✅ 添加字段名自动探测（`_find_column`），兼容 SDK 版本差异
- ✅ 实现 A 股财报披露时点对齐（`_latest_available_quarter`）
- ✅ 审计意见过滤、担保过滤、现金流警告全部落地
- ✅ 支持四种认证方式：命令行参数、环境变量、.env 文件、交互式输入

**运行命令**:
```bash
python scripts/factor.py --as-of-date 20260710 --threshold 0.80 --username '86手机号' --password '密码'
```

### 2.2 scripts/validate.py（验证脚本）

**功能**: 三层沙漏验证
- 第一层：未来函数检测（shift 对齐）
- 第二层：过拟合检测（参数敏感性）
- 第三层：样本外检测（跨年份/跨行情验证）

**运行命令**:
```bash
python scripts/validate.py --username '86手机号' --password '密码'
```

### 2.3 scripts/backtest.py（回测脚本）

**功能**: 因子回测分析
- IC / RankIC 时序
- ICIR（信息系数比率）
- 分层收益（5组，多空组合）
- 最大回撤
- 换手率
- 样本外 vs 样本内对比

**运行命令**:
```bash
python scripts/backtest.py --period 20 --username '86手机号' --password '密码'
```

### 2.4 scripts/probe_fina_fields.py（字段探测脚本）

**功能**: 探测 PandaAI SDK 返回的真实字段名，用于调参

**运行命令**:

## 四、认证方式

使用此技能需要 PandaAI 账号权限，支持以下四种认证方式：

| 方式 | 优先级 | 适用场景 |
|------|:---:|---------|
| 命令行参数 | 1 | 脚本自动化、CI/CD |
| 环境变量 | 2 | 开发环境、临时使用 |
| .env 文件 | 3 | 项目配置、团队共享 |
| 交互式输入 | 4 | 默认兜底、手动运行 |

**示例**:
```bash
# 方式一：命令行参数
python scripts/factor.py --username '<PANDA_USERNAME>' --password '<PANDA_PASSWORD>'

# 方式二：环境变量
export PANDA_USERNAME='<PANDA_USERNAME>'
export PANDA_PASSWORD='<PANDA_PASSWORD>'
python scripts/factor.py

# 方式三：.env 文件
# 创建文件：e:\因子skill集\skill-graham-netnet-screener\开发产物\.env
# PANDA_USERNAME=<PANDA_USERNAME>
# PANDA_PASSWORD=<PANDA_PASSWORD>

# 方式四：交互式输入
python scripts/factor.py
# 请输入 PandaAI 用户名（86手机号）: 
# 请输入 PandaAI 密码:
```
